## JavaScript eksempel: Iterere et array med et for-loop

```javascript
// Et array med frugter
const fruits = ["Æble", "Banan", "Appelsin"];

// For-loop der gennemgår arrayet
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```
